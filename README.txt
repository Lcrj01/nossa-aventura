# 💜🧡 Uma aventura chamada nós

Projeto de declaração romântica interativa em HTML + CSS + JavaScript.

## Como usar

1. Abra `index.html` no navegador.
2. Edite `script.js`, na parte `CONFIG`.
3. Troque:
   - `senha`
   - `inicioNamoro`
   - `distanciaKm`
4. Coloque suas fotos em `assets/photos/` com estes nomes:
   - foto1.jpg
   - foto2.jpg
   - foto3.jpg
   - foto4.jpg
   - foto5.jpg
   - foto6.jpg
5. Coloque a música em:
   - `assets/music/nossa-musica.mp3`

## Importante sobre a música

Navegadores normalmente bloqueiam reprodução automática de áudio. Por isso o site deixa o player pronto e a música pode começar depois de uma interação do visitante.

## Personalização

A declaração principal fica em `story` dentro do `script.js`.
A carta final fica diretamente no `index.html`, na seção `#letter`.

## Publicação

Você pode publicar a pasta inteira em qualquer hospedagem estática que aceite HTML/CSS/JS. Não é necessário banco de dados ou servidor.

## Observação

A estética foi feita para seguir a referência escolhida: fundo roxo espacial, detalhes laranja, neon, pixel/RPG, estrelas, corações, fotos, mapa, contador, batalha, easter egg, baú e carta final.
